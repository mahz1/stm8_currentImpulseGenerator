# stm8_currentImpulseGenerator

Порт проекта **«Модуль управления ГТИ-К»** с Arduino (ATmega328P) на STM8S105C6 (плата STM8S-Discovery).

## 📋 Описание

Устройство генерирует импульсы тока заданной амплитуды и длительности для проверки/калибровки измерительных цепей. Управление ведётся с мембранной клавиатуры 4×3, результат отображается на LCD1602 через I2C.

**Основные возможности:**
- Генерация импульсов тока (500–3000 мА).
- Задание длительности импульса (0.1–20 мс).
- Автоматический заряд конденсаторов до нужного напряжения.
- Измерение амплитуды и длительности с фильтрацией АЦП.
- Калибровка коэффициента `Ki` с сохранением в EEPROM.
- Аварийное отключение при обнаружении утечки тока.
- Русскоязычный интерфейс на LCD (знакогенератор MT-16S2H-B, страница 0x2A).

## 🔌 Распиновка

| Функция | Пин | Номер вывода (LQFP48) |
|---------|-----|------------------------|
| Светодиод LD1 | PD0 | 41 |
| Заряд | PD2 | 43 |
| Быстрый разряд | PD3 | 44 |
| Медленный разряд | PD4 | 45 |
| Импульс | PD5 | 46 |
| Предохранитель | PD6 | 47 |
| I2C SCL | PE1 | 39 |
| I2C SDA | PE2 | 38 |
| АЦП: ток (AIN0) | PB0 | 21 |
| АЦП: напряжение (AIN1) | PB1 | 22 |
| Клавиатура (строки ROW1–ROW4) | PC1–PC4 | — |
| Клавиатура (столбцы COL1–COL3) | PC5–PC7 | — |

**Питание:** VREF (VDDA) = 5 В.  
**I2C:** адрес LCD — `0x38`.  
**Клавиатура:** 7 проводов (4 строки + 3 столбца), мембранная.

## ⚙️ Как собрать

**Требования:**
- IAR Embedded Workbench for STM8 (любая версия, поддерживающая STM8S105C6).
- ST-LINK (встроен в STM8S-Discovery).
- Подключённая плата STM8S-Discovery.

**Сборка:**
1. Открой `project.eww` в IAR.
2. Проверь настройки в **Project → Options**:
   - **General Options → Target → Device**: `STM8S105C6`.
   - **Debugger → Setup → Driver**: `ST-LINK`.
   - **C/C++ Compiler → Preprocessor → Defined symbols**: `STM8S105`.
   - **C/C++ Compiler → Preprocessor → Additional include directories**: `$PROJ_DIR$\inc`, `$PROJ_DIR$\src`.
3. **Project → Rebuild All**.
4. **Download and Debug → GO**.
